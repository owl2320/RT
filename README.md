# AI Assistant

## Features

### Backend
- FastAPI backend
- PostgreSQL database
- SQLAlchemy ORM
- Alembic migrations
- User authentication
- Conversation memory
- Conversation management
- Streaming LLM responses
- Groq API integration

### Frontend
- Chat interface
- Conversation sidebar
- New conversation support
- Conversation deletion
- Persistent conversations
- Streaming responses
- Markdown rendering
- Code block rendering
- LaTeX/math rendering
